# Nebulon AI logo set — v1.1

Wordmark: official Nebulon symbol and “Nebulon” in Inter Tight Bold (700), with “AI” in Inter Tight Regular (400).
Icon: a no-links, round-dot latitude-row sphere with a violet core, in light and dark. The medium-density grid from icon v0.8 (60 rows, 84 dots at the equator).

## Colours

| Name        | Hex     |
|-------------|---------|
| Indigo      | `#3341c9` |
| Violet      | `#7b5cff` |
| Periwinkle  | `#a9b6ff` |
| Ink         | `#0d1120` |
| White       | `#ffffff` |

On the light lockup, “Nebulon” is ink and “AI” uses a gradient from violet to indigo.
On the dark lockup, “Nebulon” is white and “AI” uses a gradient from periwinkle to violet.

Light lockup gap strokes are white, for use on white or cream. Dark lockup gap strokes are ink, for use on ink or near-black.

## Fonts

- “Nebulon”: Inter Tight Bold (700), tracking −0.03
- “AI”: Inter Tight Regular (400)
- Logo files are outlined paths; the font files are not required to use them

## Files

### Icons (`icons/`)

Tiled app icons (rounded square, official 14/64 corner) and transparent marks (sphere, rings and glow only, no tile).

- `icon-light.svg` / `icon-dark.svg`
- `icon-light-transparent.svg` / `icon-dark-transparent.svg`
- PNG, each of the four variants, at 1024, 512, 256, 180 (apple-touch), 128, 64, 48, 32 and 16 pixels: `icon-light-1024.png`, and so on
- `favicon-light.ico` / `favicon-dark.ico` — 16, 32 and 48 px

### Lockups (`lockups/`)

Horizontal “Nebulon AI” lockups, light and dark, with a transparent background.

- `nebulon-ai-horizontal-light.svg` / `nebulon-ai-horizontal-dark.svg`
- `nebulon-ai-horizontal-light.png` / `nebulon-ai-horizontal-dark.png` — 2048 px wide (2× of 1024)

### Sheet

- `brand-sheet.png` — preview of the lockups, icons, sizes and colours
