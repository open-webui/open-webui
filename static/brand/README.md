# Nebulon AI brand assets

Official logo pack: `nebulon-ai-logo-v1.1/` (see its `README.md` and `brand-sheet.png`).

After updating the pack, run from the repo root:

```bash
bash scripts/install-nebulon-brand.sh
```

This refreshes `static/static/` and `backend/open_webui/static/` legacy filenames used at runtime.
