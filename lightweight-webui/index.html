Mini WebUI

A lightweight, single-file chat UI for any cloud LLM with an OpenAI-compatible API. Bring your own key — everything runs and stays in your browser.

📄 PDF & textFull text extracted in-browser and added to context.
🖼️ ImagesSent as vision input to multimodal models (auto-resized).
🎬 VideoSmart frames are captured client-side for VLM analysis.
🔒 PrivateKey & chats live in localStorage only. No middleman.
Works with OpenAI · OpenRouter · Groq · vLLM · Ollama (local) — set it in Settings
📥 Drop files to attach

⚙️ Settings

“Pull models” calls GET /models on the API and fills the suggestions. For vision/file features pick a multimodal model (e.g. gpt-4o, llama-4-scout, gemini-flash via OpenRouter).
